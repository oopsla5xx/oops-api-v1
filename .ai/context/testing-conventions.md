# Testing Conventions

## Test pyramid

| Layer | Type | Infra | Tool |
|-------|------|-------|------|
| `internal/shared/*` | Unit | None | testify/assert |
| `application/command/`, `application/query/` | Unit + mock | None | testify/mock + mockery |
| `interface/handler.go` | Integration | Real DB | tests.NewTestDB + httptest |

## Package declaration
Always use the external test package:
```go
package user_test   // NOT package user
```

## Naming
Table-driven with `t.Run` and English behavior descriptions:
```go
func TestCreateUser(t *testing.T) {
    tests := []struct{ name string; ... }{ ... }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) { ... })
    }
}
```

## Assertions
- `assert.*` — soft assertion, test continues after failure
- `require.*` — hard assertion, stops immediately on failure

Use `require` when subsequent assertions depend on the value being checked.

## Mocks
Generated by `make generate` (mockery), placed at `<module>/domain/mocks/`.

```go
repo := mocks.NewMockUserRepository(t)
repo.EXPECT().FindByID(ctx, id).Return(user, nil)
```

Re-run `make generate` after changing any repository interface.

## Factory
Add `internal/tests/factory/<entity>.go` for each new entity using the functional overrides pattern:
```go
type UserInput struct{ Email, Name string }

func NewUser(overrides ...func(*UserInput)) UserInput {
    u := UserInput{Email: gofakeit.Email(), Name: gofakeit.Name()}
    for _, o := range overrides { o(&u) }
    return u
}
```

## Integration test setup
```go
func TestHandler_CreateUser(t *testing.T) {
    pool := tests.NewTestDB(t)
    t.Cleanup(func() { tests.Truncate(t, pool, "users") })
    gin.SetMode(gin.TestMode)
    ...
}
```

## TestMain
Use only in packages that need global setup (e.g. deterministic factory seed):
```go
func TestMain(m *testing.M) {
    factory.Seed(42)
    m.Run()
}
```

## Coverage thresholds
- CI fails if total < **90%**
- CI warns if any package < **80%**
- Excluded: `docs/`, `internal/infrastructure/database/sqlc/`, `cmd/api/`

## Reference examples
- Unit test: `internal/shared/errors/errors_test.go`
- Handler test: `internal/modules/health/interface/handler_test.go`
- Full agent workflow: `internal/tests/AGENTS.md`
